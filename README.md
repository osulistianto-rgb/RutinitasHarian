# Rutinitas+ v2.0

## Isi repository
- `index.html`
- `.github/workflows/build-apk.yml`

## Fitur APK
- WebView Android untuk Rutinitas+ v2.0
- Pilih foto dari galeri
- Ambil foto dari kamera
- Pilih lampiran dan dokumen
- Simpan PDF
- Simpan cadangan `.rtns`
- Pulihkan cadangan melalui pemilih file Android

## Build
1. Upload seluruh isi folder ini ke root repository GitHub.
2. Buka tab **Actions**.
3. Pilih **Build APK Rutinitas Plus v2.0**.
4. Tekan **Run workflow**.
5. Setelah selesai, unduh artifact **Rutinitas-Plus-v2.0-APK**.
